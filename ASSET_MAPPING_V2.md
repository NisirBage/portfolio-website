# Asset Mapping V2 — The Studio

**Status:** Draft for review. Full re-audit of both asset packs against the hub-and-spoke Studio model and the Narrative System's Object Story Rules — every asset must answer "why does this exist here" or it's cut. This supersedes Phase 1's asset utilization matrix, which was written for the five-room model.

Certificate images (the College Compendium folder and the two large PDFs) are content assets, not reusable design assets — they're tracked in the Strategy doc's content inventory and Content Hierarchy, not here.

## Net Object Count

Cross-referencing this audit against Interaction Specification's six world-visible hotspots confirms every one is backed by a real, already-owned asset (Desk and Bookshelf from Furniture State 1, Leadership Frames and Coffee Mug from Small Items, Clock — present in Furniture State 1's clock sprite, confirmed reusable as a standalone hotspot — and Window from Doors & Windows). **No new pixel art needs to be commissioned or generated for V1.** The only genuinely new visual work required is the modern-UI panel system itself (Phase 1's glassmorphic layer), which was never asset-pack-dependent to begin with.
